Open source

Fixes and features merged upstream in the Ruby & AI libraries I build on.

Most of my open-source work goes into the projects my own Rails and AI code depends on — RubyLLM and ActiveAgent today, React on Rails and Rails-ecosystem gems before that. The common thread is reliability: cancellation and concurrent tools, provider protocols, attachments, structured output, tracing, evals and cost accounting, and making it all behave inside a Rails app.

Every entry below is a pull request a project's own maintainers merged into their repository. Forks, private repositories and employer code are left out.
