Learning MCP by fixing it

Nine pull requests to RubyLLM's MCP client, and what each bug taught me about the Model Context Protocol.

Sessions#1401

BugTwo requests saw the same session end. Both opened a new one, and one was never closed.

FixOpen a new session only if the one that ended is still the current one.

Compare identity, not presence.
stdio#1402#1403#1404

BugA restarted server process still got the token from the first start.

FixRead env each time the process starts, and test that app secrets never reach it.

Read values when the thing that uses them starts.
OAuth#1425#1426#1432#1578

BugA token refresh could write credentials back after the user disconnected.

FixEvery write takes the same per-key lock and reads the store again inside it.

A lock is about order.
Outages#1577

BugOne tenant's broken proxy hid a server's tools from every tenant on that URL.

FixKey the backoff on the URL plus the connection settings.

Key on everything that changes the outcome.
